# محرر فوتوشوب PSD على الويب (PSD Web Studio)

تطبيق ويب متقدم واحترافي لتحميل وقراءة وتحرير وتصدير ملفات **Photoshop PSD** متعددة الطبقات (Layered PSD) مباشرة في المتصفح على أجهزة الكمبيوتر والهواتف الذكية مع دعم كامل للغة العربية والربط السحابي مع Google Drive.

---

## ✨ المميزات الرئيسية

### 1. معالجة طبقات الفوتوشوب (PSD Layer Engine)
- رفع وقراءة ملفات `.psd` الحقيقية واستخراج أبعاد التصميم ودقة الـ DPI.
- تحليل واستخراج جميع الطبقات (Layers) والمجموعات (Nested Groups).
- دعم طبقات النصوص (Text Layers) مع استخراج النص والخط والحجم واللون والمحاذاة.
- دعم طبقات الصور (Raster Images) والكائنات الذكية (Smart Objects) وأقنعة القص (Clipping Mask).
- دعم الشفافية (Opacity)، أوضاع المزج (Blend Modes: Multiply, Screen, Overlay, etc.)، وتأثيرات الظلال (Drop Shadows).
- إظهار/إخفاء الطبقات (👁️) وقفلها لمنع التحريك (🔒)، وتكرار الطبقات وحذفها وإعادة ترتيبها.

### 2. محرك النصوص العربية وتنسيق الفقرات (Arabic Typography & Paragraphs)
- **تنظيم الفقرات التلقائي**: زر ذكي لتنظيم وتنسيق الأسطر المتناسقة ومحاذاة الضبط الكامل (`Justify`) لتتساوى كل الأسطر في العرض.
- **التباعد بين الأسطر (Line Spacing)**: شريط تمرير تفاعلي مع نسب جاهزة (1.2x مضغوط، 1.4x متناسق، 1.6x مريح، 2.0x واسع).
- **تمديد الحروف والكشيدة العربية (Kashida / Tatweel)**: إمكانية تمديد الحروف أو إزالة المد بضغطة زر.
- **مكتبة خطوط عربية ثرية**: خطوط ثمانية (Thmanyah Serif Display بجميع أوزانها الخمسة)، إكسو (Exo)، القاهرة (Cairo)، تجوال (Tajawal)، المراعي (Almarai)، الأميري (Amiri).
- **نظام رفع الخطوط المخصصة**: رفع وتثبيت أي خط (`.ttf`, `.otf`, `.woff`, `.woff2`) وتطبيقه فورياً.

### 3. التخزين السحابي والربط مع Google Drive
- إمكانية حفظ ورفع القوالب مباشرة إلى مجلد سحابي خاص في حسابك على **Google Drive**.
- تصفح واستيراد وتعديل القوالب المخزنة على Google Drive بنقرة واحدة.
- دعم تنزيل نسخ احتياطية للملفات بصيغة `.json` مستقلة.

### 4. استبدال الصور والكائنات الذكية بالأبعاد الطبيعية (Image Replacement)
- استبدال أي صورة مع الحفاظ على الأبعاد الطبيعية ومنع التشويه والتمطيط.
- شريط تكبير وتصغير الصورة (Image Scale Slider) من 10% إلى 300% مع أزرار النسب السريعة وزر الاستعادة للحجم الطبيعي.

### 5. مساحة العمل التفاعلية والتحويل (Transform & Canvas)
- تكبير وتصغير (Zoom In / Out / Fit / 100%) وتحريك مساحة العمل (Pan & Hand Tool).
- مقابض تحجيم وتدوير تفاعلية (8-point Bounding Box Gizmo).
- نظام تراجع وتقدم تفاعلي دقيق (`Ctrl+Z`, `Ctrl+Shift+Z`) لكل حركة أو تعديل.
- تجربة متجاوبة بالكامل للهواتف الذكية (Mobile First).

### 6. التصدير بدقة فائقة (Export System)
- تصدير PNG بدقة عالية مع دعم الخلفية الشفافة.
- تصدير JPG مع التحكم بمستوى الجودة.
- تصدير PDF مجهز للطباعة والمستندات.
- مضاعفة دقة التصدير (1x أصلي، 2x HD، 4x Ultra 4K).

## 🚀 طريقة التشغيل والبدء السريع

### 1. تثبيت الحزم:
```bash
# تثبيت الحزم الرئيسية وحزم الواجهة والسيرفر
npm run install:all
```

### 2. تشغيل السيرفر والواجهة معاً:
```bash
npm run dev
```
- **رابط الواجهة**: `http://localhost:5173`
- **رابط السيرفر**: `http://localhost:5000`

---

## ☁️ إعداد الربط مع Google Drive API (اختياري)

1. ادخل على [Google Cloud Console](https://console.cloud.google.com/).
2. أنشئ مشروعاً جديداً وفعّل خدمة **Google Drive API**.
3. من قسم **Credentials**، أنشئ **OAuth 2.0 Client ID** من نوع *Web Application*.
4. في خانة **Authorized JavaScript origins** ضع رابط موقعك (مثال: `http://localhost:5173`).
5. انسخ **Client ID** وضعه في نافذة **Google Drive** داخل الموقع، وسيتم الاتصال ورفع القوالب فوراً.

## 🐙 خطوات رفع المشروع على GitHub

المشروع مجهز بالكامل بملف `.gitignore` لاستبعاد الملفات المؤقتة والـ `node_modules`.

### الخطوة 1: تهيئة مستودع Git
إذا كان برنامج `git` مثبتاً على جهازك:
```bash
# 1. تهيئة المستودع
git init

# 2. إضافة جميع ملفات المشروع
git add .

# 3. حفظ أول Commit
git commit -m "Initial commit: PSD Web Studio with Google Drive & Typography"

# 4. ربطه بمستودعك على GitHub
git remote add origin https://github.com/USERNAME/REPOSITORY_NAME.git
git branch -M main

# 5. الرفع إلى GitHub
git push -u origin main
```

### أو عبر GitHub Desktop أو VS Code:
1. افتح مجلد المشروع في **VS Code**.
2. من القائمة الجانبية اليسرى اضغط على أيقونة **Source Control** (أو `Ctrl + Shift + G`).
3. اضغط على **"Publish to GitHub"**.
4. اختر مستودعاً عاماً (Public) أو خاصاً (Private) وسيتم رفع كامل المشروع تلقائياً.

## 🏗️ الهيكلية المعمارية للمشروع

```
psd-web-studio/
├── client/                     # الواجهة الأمامية (React + Vite + TypeScript + Tailwind)
│   ├── src/
│   │   ├── components/         # مكونات الكانفاس، الألواح، النوافذ، والأشرطة
│   │   ├── services/           # محرك تحليل PSD، الخطوط، التصدير، Google Drive، وتنسيق الفقرات
│   │   ├── store/              # إدارة الحالة والتراجع (Zustand)
│   │   └── views/              # شاشات المحرر، لوحة التحكم، والمكتبة
│   └── public/fonts/           # خطوط ثمانية و Exo
├── server/                     # الخادم (Express + TypeScript)
│   └── src/                    # واجهات API للمشاريع والقوالب وإدارة المشرف
├── .gitignore                  # استبعاد الملفات غير الضرورية من الرفع
└── package.json                # سكربتات التشغيل والبناء الموحدة
```
